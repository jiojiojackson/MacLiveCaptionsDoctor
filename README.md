# 实时字幕语言诊断（LiveCaptionsDoctor）

## 使用方法
1. 解压 zip，打开「终端」
2. 输入 `bash ` （注意后面有空格），把解压出的 `build.sh` 拖进终端窗口，回车
3. 第一次如果提示安装 Xcode 命令行工具，点「安装」，装完再运行一次
4. 编译成功会自动打开 App；以后直接双击 `LiveCaptionsDoctor.app`

编译失败时，错误会**自动复制到剪贴板**，直接粘贴给 Quick。

## 功能
- 列出系统所有离线语音语言，显示：已就绪 / 部分就绪 / 下载中 / 需下载 / 不支持
- 每种语言分别检查「转写模型」「听写模型」「传统离线识别」
- 下载按钮 + 实时进度条（百分比和 MB）；系统已在下载的可以「跟踪进度」
- 每 15 秒自动刷新状态；状态变化会写入日志
- 日志区每 20 秒自动收集实时字幕 / 语音 / 资源下载相关的系统日志，错误标红
- 「一键复制诊断报告」「仅复制错误」「保存到桌面」
- 「深度扫描」：检查系统语音资源目录、实时字幕进程和偏好设置

## 已验证的结论（macOS 27.2.1）
- 实时字幕（进程名 `Live Captions`）用的是系统“转写模型”：`com.apple.speech.asr.transcription.<语言>`（en / cmn / ja / fr …），同一语言的不同地区共用一个模型。
- 只要“转写模型”装好，实时字幕就能用；“听写模型”与实时字幕无关。
- 在实时字幕里选择一个没下载的语言，系统会在后台自动下载；下载完成前实时字幕会跳过声音（日志：`assets are not ready progress: N`），所以“能选但不出字”。

## 说明
- Apple 没有公开“实时字幕自己的语言列表”接口。本工具检查的是 macOS 26+ 系统共享的离线语音模型
  （SpeechAnalyzer / AssetInventory），并同时收集实时字幕进程（LiveTranscriptionAgent）的日志。
- 通过本工具下载的语言会被本工具“预留”。系统对预留数量有上限，满了会下载失败，可在「预留语言」里释放。
